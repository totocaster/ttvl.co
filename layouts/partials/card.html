{{- /* A card: a 16:9 tile, one label line, the title, the dek. Pass "page"; pass "variant" "trace" for trace pages, whose description, image, and kind live outside project front matter, or "research" for a research entry: its `image`, else the first figure or clip poster in its text, contained on a white plate (or the page ground for image_presentation: cutout); an entry without one shows its number and kind on the tile. Research cards read "date · stream" and carry no dek. The label line: projects read "date · hub" (the hub is the title, or filter_label, of the page named by project.category); ongoing work reads "Since YYYY · hub"; traces read "date · kind". Optional project.since (a year) and project.kind (a word) override the year and the hub for work without a category. A project card always carries data-category (empty without a hub) so the Projects filter hides it under any one hub and shows it when no switch is pressed. docs/styleguide.md, Cards. */ -}} {{- $page := .page -}} {{- $variant := .variant | default "project" -}} {{- $img := "" -}} {{- $desc := "" -}} {{- $category := "" -}} {{- $label := slice -}} {{- $number := "" -}} {{- if eq $variant "research" -}} {{- $img = $page.Params.image -}} {{- if not $img -}} {{- with findRESubmatch `(?:(?:src|poster)="|\]\()(/visuals/[^")\s]+\.(?:png|jpe?g|webp|gif))` $page.RawContent 1 }}{{ $img = index (index . 0) 1 }}{{ end -}} {{- end -}} {{- $number = partialCached "research-number.html" $page $page.Path -}} {{- $d := $page.Date.Format "2006-01-02" -}} {{- $label = slice (printf `%s` $d $d) (htmlEscape $page.CurrentSection.Title) -}} {{- else if eq $variant "trace" -}} {{- $img = $page.Params.image -}} {{- $desc = $page.Params.description -}} {{- $category = $page.Params.trace.kind -}} {{- with $page.Date }}{{ if not .IsZero }}{{ $label = $label | append (printf `%s` (.Format "2006-01-02") (.Format "2006-01-02")) }}{{ end }}{{ end -}} {{- with $page.Params.trace.kind }}{{ $label = $label | append (htmlEscape .) }}{{ end -}} {{- else -}} {{- $proj := $page.Params.project | default (dict) -}} {{- $img = $proj.image -}} {{- $desc = or $proj.description $page.Params.description -}} {{- with $proj.category }}{{ $category = trim . "/" }}{{ end -}} {{- if eq (printf "%v" $proj.year) "ongoing" -}} {{- $since := $proj.since -}} {{- if not $since -}} {{- with $page.RegularPages.ByDate }}{{ $since = (index . 0).Date.Year }}{{ else }}{{ if not $page.Date.IsZero }}{{ $since = $page.Date.Year }}{{ end }}{{ end -}} {{- end -}} {{- $label = $label | append (cond (ne (printf "%v" $since) "") (printf `Since %v` $since) "Ongoing") -}} {{- else if not $page.Date.IsZero -}} {{- $label = $label | append (printf `%s` ($page.Date.Format "2006-01") ($page.Date.Format "2006-01")) -}} {{- end -}} {{- with $proj.kind -}} {{- $label = $label | append (htmlEscape .) -}} {{- else -}} {{- with $proj.category }}{{ with site.GetPage . }}{{ $label = $label | append (printf `%s` (htmlEscape (.Params.filter_label | default .Title))) }}{{ end }}{{ end -}} {{- end -}} {{- end }}
