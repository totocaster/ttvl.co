I've started the practical side of this stream: a studio environment system for [Project Humane](/project-humane/), built in and for our studio in Rome. The project is called _Studio Humane_.

The first step is a virtual copy of the studio: a 3D model accurate enough to point at a single drawer. With it I want to find out how useful such a twin really is, and how much of the studio I can run through displays, voice, macropads, and small tools spread around the room, so the studio becomes a more pleasant and more useful place to work.

A Blender script generates the model, which is exported as a GLB and shown in a browser viewer that runs offline from a single file.
