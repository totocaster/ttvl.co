The practical way of notating 8-string guitar is a piano-style grand staff. Treble for the upper register, bass for the lower register, both still octave-transposed for guitar. The version I like is the balanced split, with four open strings on each staff, rather than keeping the top six strings in treble and using bass only for strings 7 and 8.

![Grand staff reference for 8-string guitar, open to fourth fret](/visuals/8-strings/grand-staff-open-to-4th-fret.png)

That matters because it treats the 8-string as its own instrument. The extra range is not just an attachment to 6-string notation. If the point is new voicings and wider register control, the page should show that structure clearly.

Use the staves pragmatically. High-register passages can use two treble staves. Low-register passages can use two bass staves. Two-hand tapping can split by hand. This is not a new notation system; it is the existing grand-staff logic applied to an extended-range guitar.

The companion PDF is useful as a boring reference sheet: first-position notes, sharps, flats, string numbers, fret numbers, and a separate map for strings 7 and 8.
