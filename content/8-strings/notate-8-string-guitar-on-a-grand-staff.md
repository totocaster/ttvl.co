Standard guitar notation already sounds an octave lower than written. That works well enough for 6-string guitar, but it breaks down on 8-string: the low F# sits too far below a single treble staff.

Bass clef alone is not better. It cleans up the low strings and makes the upper register awkward. It also throws away the treble-clef reading skill guitarists may already have.

The practical answer is a piano-style grand staff: treble for the upper register, bass for the lower register, both still octave-transposed for guitar. The version I like is the balanced split, with four open strings on each staff, rather than keeping the top six strings in treble and using bass only for strings 7 and 8.

That matters because it treats the 8-string as its own instrument. The extra range is not just an attachment to 6-string notation. If the point is new voicings and wider register control, the page should show that structure clearly.

Use the staves pragmatically. High-register passages can use two treble staves. Low-register passages can use two bass staves. Two-hand tapping can split by hand. This is not a new notation system; it is the existing grand-staff logic applied to an extended-range guitar.

The companion PDF is useful as a boring reference sheet: first-position notes, sharps, flats, string numbers, fret numbers, and a separate map for strings 7 and 8.
